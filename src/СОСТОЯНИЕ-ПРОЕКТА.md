# Сахалыы саҥар — самоучитель разговорного якутского

Приложение на одном HTML-файле, без сервера и без интернета. Автор — Евсеев А.В.
Состояние на 20 октября 2026 года.

## Что это

Самоучитель разговорного якутского (саха) языка: упор на живые фразы, а не на грамматику.
Работает на телефоне и компьютере, весь звук, словарь и шрифты внутри, сеть не нужна.

Содержание:
- 17 уроков, 178 фраз;
- диалоги, 85 реплик;
- список для заучивания, 259 слов, с интервальным повторением;
- словарь, 2952 слова;
- разделы «Звуки», мини-грамматика, марафон (тренировка вперемешку).

## Оформление (с 20 октября 2026)

- Две темы, выбираются по настройке телефона. Принцип инверсии, как в «Уус бул»: меняются местами
  фон, кнопки и сам знак.
  - **Светлая:** тёплый светлый фон `#F5F3EE`, тёмно-синие кнопки `#16306B`, золотые акценты `#B07F22`,
    знак — светлая версия (тёмное золото, синяя река), название золотом.
  - **Тёмная:** ночной синий фон `#081128`, золотые кнопки, голубой прогресс `#7CC3FF`,
    светящийся знак, название светлым золотом.
- Шапка главной: знак + «Сахалыы / саҥар», под описанием — золотая полоса-орнамент.
- Заставка при запуске всегда тёмная: знак, название, «самоучитель якутского языка». Держится 1,5 с и
  плавно исчезает. Для iPhone есть такие же картинки запуска (10 размеров), чтобы не мелькал белый экран.
- Иконка на рабочем столе — тёмная (одна на обе темы: у веб-приложений иконка от темы не меняется).
  Для круглой маски Android — отдельная иконка с запасом по краям.
- Шрифты внутри приложения: **Onest** — интерфейс, **PT Serif** — якутский текст. Оба поддерживают
  ҕ ҥ ө һ ү. Google Fonts больше не используется.
- Название набирается шрифтом, а не берётся с картинки: на присланных картинках с текстом вместо
  якутской **ҥ** нарисована казахская **ң**.
- Особые буквы ҕ ҥ ө һ ү в фразах по-прежнему подчёркнуты золотом.

## Как собрано

Исходники собираются скриптом `sborka.py`:

| Файл | Что это |
|---|---|
| `app.html` | весь код приложения: разметка, стили, логика, уроки, диалоги, слова |
| `dict.json` | словарь: массив `["слово", "часть речи", "перевод", "англ. значение"]` |
| `sborka.py` | сборка обеих версий |
| `sw.js` | service worker: офлайн-работа и обновления (заготовка с метками) |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | иконки |
| `emblem-dark.webp`, `emblem-light.webp` | знак для тёмной и светлой темы; сборка встраивает их в страницу |
| `fonts/*.woff2` | шрифты Onest и PT Serif, лицензии `OFL-*.txt` там же |
| `splash/launch-*.png` | картинки запуска для iPhone (только версия для сайта) |
| `ozvuchka/audio-*.json` | **в проект не входит**, хранится отдельно: озвучка, 4 файла, 19 МБ |

Картинки, шрифты и иконки — в архиве `sakhalyy-sanar-ishodniki.zip` (текстовые файлы там тоже есть).

`manifest.webmanifest` отдельным файлом не хранится: его содержимое записано в `sborka.py`
(константа `MANIFEST`), сборка создаёт файл сама.

Метки в `app.html`, которые подставляет сборка: `/*DICT*/[]` — словарь,
`/*AUDIO_FILES*/[]` — список файлов озвучки, `<!--PWA-->…<!--/PWA-->` и
`<!--PWA-HEAD-->…<!--/PWA-HEAD-->` — куски, которые нужны только версии для сайта.
Кроме того, сборка заменяет имена `emblem-dark.webp` и `emblem-light.webp` встроенными картинками
(в `app.html` каждое имя должно встречаться ровно один раз), а в офлайн-файле — ссылки
`url(fonts/…)` встроенными шрифтами. В `sw.js` есть метка `/*FONT_FILES*/[]` — список шрифтов для кеша.

Команды:

    python3 sborka.py site      # build/site/ — версия для сайта (29 файлов, 23 МБ)
    python3 sborka.py offline   # build/sakhalyy-sanar-offline.html — один файл, 19,8 МБ
    python3 sborka.py both      # и то и другое

Без папки `ozvuchka` приложение соберётся, но без встроенного звука: код скрипта
это допускает и предупреждает. **Перед сборкой папку с озвучкой нужно приложить в чат.**
Файлы из «знаний» проекта Claude может только прочитать, но не получить как файлы, поэтому
для сборки исходники тоже нужно прикладывать в чат.

## Две версии

- **Версия для сайта (PWA).** Код отдельно (620 КБ), озвучка в 4 файлах, шрифты в папке `fonts`.
  Ставится на экран «Домой» на iPhone (Safari → Поделиться) и через «Установить приложение» в Chrome
  на Android. После первого открытия работает без сети (проверено: страница, шрифты и вся озвучка
  берутся из кеша). Когда на сайте появляется новая версия, показывает плашку «Доступна новая версия»
  и обновляется, сохраняя данные пользователя. **Адрес сайта менять нельзя**: по нему привязаны
  сохранённые данные.
- **Офлайн-файл.** Всё одним HTML, включая шрифты и знаки. Для устройств без интернета. Сам не обновляется.

## Размещение сайта

- Создан репозиторий GitHub **EvsAV37/sakhalyy-sanar** (публичный). Claude может загружать в него
  файлы, но не может создавать репозитории и включать GitHub Pages — это делает владелец.
- Включить показ сайта: Settings → Pages → Source: «Deploy from a branch» → ветка `main`,
  папка `/ (root)` → Save. Адрес будет `evsav37.github.io/sakhalyy-sanar`.
- Советовали до раздачи ссылки купить свой домен и направить его на GitHub Pages: тогда хостинг
  можно сменить, не меняя адрес и не теряя данные пользователей («Уус бул» так переезжал
  с github.io на свой домен).

## Принятые решения

- **Озвучка** — Silero, модель `v5_turkic`, голос **sah_0**, обычный темп (пробовали
  замедление на 10 и 15%, отказались). MP3 моно 24 кГц 48 кбит/с, без обрезки тишины
  и без добавленных пауз. Озвучено 3143 уникальные записи (3208 ключей в файлах озвучки):
  все фразы, реплики и слова словаря.
  Прежнюю озвучку из Яндекс Переводчика заменили полностью.
- **5 слов не озвучены**: үҥүү, үһү, өҥ, өһүө, өһөө — на них модель выдаёт ошибку.
  Обходные написания (үҥ-үү) работают, но искажают произношение. Можно записать
  своим голосом.
- **Плитки при сборке фразы не озвучиваются** — звучит только собранная фраза целиком,
  после «Проверить».
- **В словаре** у каждого слова есть запись своим голосом (она важнее встроенной),
  можно добавлять свои слова; при совпадении приложение предупреждает о дубле.
  Переводы встроенных слов пока не редактируются — договорились добавить в обновлении.
- **Поиск в словаре**: при запросе по-русски сверху русское слово, по-якутски — якутское.
  Ищет и внутри слов: по запросу «река» находит «подстрекать». Можно при желании
  ограничить поиском по целым словам.
- **Исправление фраз** — кнопка «Править» внутри урока, вверху справа.
- **Данные пользователя** (прогресс, свои слова, записи) хранятся на устройстве,
  переносятся файлом резервной копии через «Настройки». Ключи хранения и формат копии
  при смене оформления не менялись.

## Замечено, но пока не исправлено (ждёт решения)

- В «Марафоне» у слов словаря написано «С озвучкой пока N; остальные зазвучат, когда пришлёте
  пакеты слов» — осталось от озвучки через Яндекс; N считает только 259 слов для заучивания.
- Экран «Озвучка на телефоне», выгрузка фраз и загрузка пакета остались в коде без кнопок.
- В установленной версии и офлайн-файле в «Настройках» видна служебная строка
  «Состояние: Скачанная копия — хранение в браузере».
- В `dict.json` слово «нууччалаа» записано дважды.

## Чтобы пересобрать озвучку (нужно редко)

Требуется разрешить доступ к `models.silero.ai` и `download.pytorch.org`.
Сборка torch с download.pytorch.org не ставится (перенаправление на
download-r2.pytorch.org, он закрыт) — ставится обычный torch с PyPI, на процессоре
работает так же. Модель: `https://models.silero.ai/models/tts/ru/v5_turkic.pt`,
голос `sah_0`, частота 48000, дальше перекодировка в MP3 через ffmpeg
(`-ar 24000 -ac 1 -b:a 48k`), без фильтров тишины. Ключи в файлах озвучки —
id фраз, реплик (`<id диалога>l<номер>`) и слов (`dw:<слово>` для словарных).

## Чтобы пересобрать оформление (нужно редко)

Знаки вырезаны из картинок пользователя: тёмный — из иконки без текста (отделён от фона с учётом
свечения), светлый — из иконки на белом. Картинки запуска iPhone отрисованы в браузере с той же
вёрсткой, что заставка, и сжаты до 256 цветов. Шрифты взяты из пакетов `@fontsource` (PT Serif)
и из «Уус бул» (Onest), латиница урезана до нужных знаков.
